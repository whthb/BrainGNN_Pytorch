# BrainGNN Course Report

This directory contains the LaTeX scaffold for the final BrainGNN course report.

Compile from this directory:

```bash
./build.sh
```

The output PDF is written to:

```text
build/main.pdf
```

The document uses `ctexrep` and is compiled with the project-local Tectonic
environment installed at `../../.conda/latex/bin/tectonic`.
